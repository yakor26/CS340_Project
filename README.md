# Midnight Slate Publishing House – CS340 Portfolio Project

# Overview
This portfolio project for CS 340, uses NodeJS, Handlebars, and JavaSript. It implements CRUD functionality for 5 entities and 3 intersection tables to represent database of fictional company Midnight Slate Publishing House to manage: Books, Authors, Orders, Buyers, Formats, and the relationships that exist between them.

# Application Tech: 
- NodeJS
- Handlebars Template Engine
- MariaDB
- Javascript
- CSS
